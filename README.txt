C / C++ -> EXE  (отдельное приложение на WebView2)
====================================================

Это не скрипт, а настоящее Windows-приложение: интерфейс сделан на HTML,
а вся логика - на C#. Собирается в один .exe, который можно отправить
другим - у них не должно требоваться ничего, кроме Windows.

ШАГ 1 - один раз поставить инструмент для сборки (не для запуска!)
--------------------------------------------------------------
Это нужно только ТЕБЕ, чтобы собрать приложение. Человеку, которому ты
потом отдашь готовый .exe, этот шаг делать не нужно.

Поставь .NET 10 SDK:
  https://dotnet.microsoft.com/download/dotnet/10.0
  (или в терминале: winget install Microsoft.DotNet.SDK.10)

ШАГ 2 - собрать
--------------------------------------------------------------
Дважды кликни Build.bat.
В первый раз нужен интернет - дотнет скачает один пакет (WebView2).
Дальше можно собирать и без интернета.

Готовый файл появится здесь:
  publish\CppToExe.exe

Это один-единственный файл. Его можно переименовать, перенести на
флешку, отправить другу - запускается двойным кликом.

ШАГ 3 - пользоваться
--------------------------------------------------------------
1. Открой CppToExe.exe
2. Если видишь "компилятор не найден" - нажми "Установить компилятор"
   (ставит gcc/g++ через winget, один раз)
3. Перетащи .c/.cpp файл в окно (или нажми на него, чтобы выбрать)
4. Нажми "Собрать exe"
5. Нажми "Запустить", чтобы увидеть результат - окно не закроется
   само, если включена галка "Пауза при выходе"

О WebView2
--------------------------------------------------------------
Это тот же движок, что в Microsoft Edge. На Windows 11 он уже встроен.
На Windows 10 почти всегда тоже уже есть (ставился вместе с обновлениями
начиная с конца 2022). Если его вдруг нет - при запуске программа честно
покажет окно с ошибкой и ссылкой, что поставить.

Если что-то не собралось или не запустилось
--------------------------------------------------------------
Скопируй текст ошибки (из окна Build.bat или из самого приложения)
и пришли Claude - разберёмся и поправим.
