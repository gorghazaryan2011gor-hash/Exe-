# C / C++ → EXE

Маленькое Windows-приложение: перетаскиваешь `.c` / `.cpp` файл — получаешь
рабочий `.exe`. Интерфейс сделан на HTML и работает через WebView2, вся логика
сборки — на C# (WinForms). Под капотом — настоящий gcc/g++ (MinGW), никакого
притворства: что видно в окне вывода, то реально происходит.

## Возможности

- Drag-and-drop или выбор файла через диалог
- Компилирует `.c` через `gcc`, `.cpp` / `.cc` / `.cxx` через `g++`
- Настройки сборки: статическая линковка (`-static`), оптимизация (`-O2`),
  без консольного окна (`-mwindows`)
- Автоматически находит компилятор (PATH, MSYS2, WinLibs) или ставит его
  через `winget` одной кнопкой
- Создаёт `*_run.bat` рядом с exe, чтобы консоль не закрывалась мгновенно
  после завершения программы
- Собирается в один exe-файл — HTML-интерфейс зашит внутрь сборки

## Требования

**Чтобы пользоваться готовым `.exe`:**
- Windows 10 (с обновлением за ноябрь 2022 или новее) или Windows 11 —
  на обеих уже есть WebView2 Runtime
- gcc/g++ не обязателен заранее — приложение само предложит поставить

**Чтобы собрать проект из исходников:**
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- Интернет при первой сборке (скачивается NuGet-пакет WebView2)

## Сборка

```bash
git clone <ссылка-на-этот-репозиторий>
cd CppToExe
Build.bat
```

Готовый файл появится в `publish\CppToExe.exe`.

Либо вручную:

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

## Использование

1. Запусти `CppToExe.exe`
2. Если компилятор не найден — нажми **«Установить компилятор»**
3. Перетащи `.c`/`.cpp` файл в окно
4. Нажми **«Собрать exe»**
5. Нажми **«Запустить»**, чтобы увидеть результат

## Структура проекта

```
CppToExe/
├── CppToExe.csproj     # проект .NET 10 / WinForms
├── Program.cs           # точка входа
├── MainForm.cs           # вся логика: поиск компилятора, сборка, мосты с UI
├── wwwroot/index.html    # интерфейс (HTML/CSS/JS), зашивается в exe
├── Build.bat             # сборка в один клик
└── README.md
```

## Известные ограничения

- Только Windows (WebView2 и WinForms — Windows-only)
- Поддерживаются только C и C++ (gcc/g++); другие языки не компилирует
- Компилятор нужно ставить отдельно (через встроенную кнопку или вручную)
